## Architectural Approaches (MCP is one of four)

The overview page calls out custom MCP servers as **one of four** supported architectures, citing security advantage:
> "The agent physically cannot run destructive commands because the server doesn't expose them."

This means the "MCP track" framing is a **strategic choice**, not a separate prize bucket — winning still requires beating non-MCP entries on the judging rubric below.

## Judging Criteria (priority order)

1. **Autonomous execution quality** (tiebreaker).
2. **Incident response accuracy**.
3. **Analytical breadth and depth**.
4. **Constraint implementation** (architectural — e.g., MCP exposure surface — beats prompt-based guardrails).
5. **Audit trail quality**.
6. **Usability and documentation**.
